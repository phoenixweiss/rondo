# Super Nintendo / Super Famicom

The owner accepted SNES play on RG34XXSP and subsequently confirmed the gameplay-button and volume stutter fixes with candidate 228786831d10. Sustained performance and full-game compatibility remain unmeasured. `.sfc` and `.smc` files route to pinned Supafaust, independently of FCEUmm, Gambatte and gpSP. `--snes-core` overrides the sibling `mednafen_supafaust_libretro` library. Missing cores and rejected games return to the recoverable error screen. Existing game/save identities are unchanged.

Supafaust is an experimental Mednafen SNES module for multicore systems, including Cortex-A53. It is not Snes9x. Its GPLv2 source and all per-file notices are included in the source-complete package, preserving Rondo's MIT grant. No proprietary SNES firmware is downloaded or bundled. Special-chip compatibility is limited to the selected core and requires individual checks; integration does not establish support for every cartridge or every stage of a game.

H700 uses the pinned GCC SDK, platform=unix, Cortex-A53 tuning, the multithreaded PPU and an empty GIT_VERSION. macOS uses the core's existing condition-variable semaphore implementation (`MDFN_USE_CONDVAR_SEMAPHORES`), because macOS does not provide POSIX unnamed semaphores/sem_timedwait. No upstream source patch is applied. CPU-affinity masks are set to 0x0, allowing the OS to schedule both threads rather than pinning emulation to CPU 1 and PPU to CPU 0. Run-ahead and multitap remain disabled. Core defaults select automatic region detection, original chip speeds and native audio rate without its optional output resampler.

Controls: directions, A/B/X/Y, L/R, Start/Select. On keyboard, Z/X are A/B, S/A are X/Y, Q/E are L/R, Enter/Right Shift are Start/Select. Menu/Tab opens the game menu. Handheld and SDL-controller face/shoulder buttons retain their labels. Held gameplay input is consumed until release after menus, state loading and sleep.

Aspect fit uses the core's reported display ratio, including its regional pixel-aspect correction, and preserves borders. Integer scaling uses complete source pixels, centred on the 720×480 display. Standard 256×224 output fits at 2×; PAL and high-resolution/interlaced modes are checked separately. They are not stretched to fill every pixel of the panel.

Cartridge SRAM uses the core's exposed size. Manual slots with previews, automatic/previous saves, explicit continuation and suspend reuse existing policies. Explicitly closing a game clears its startup offer, preserving its saves and Recent entry. Compatibility checks include the core binary and ROM hash: save states are not promised portable across architectures or core versions. Own states and SRAM are the test inputs; no foreign states are loaded.

The original MIT technical fixture exercises NTSC video, all twelve joypad buttons and SRAM. Native checks also create isolated copier-header SMC and PAL variants, test separate shell/runner processes, state roundtrips, restart and injected sleep. Its audio is silent; audio-frame delivery and real owned-game audio are distinct checks. These fixtures are source/CI material, not games installed into the user's library. Commercial ROM/artwork test kits and private results remain outside Git and the generic frontend ZIP.

Upstream: [Supafaust](https://github.com/libretro/supafaust), [README](https://github.com/libretro/supafaust/blob/master/README.md), [COPYING](https://github.com/libretro/supafaust/blob/master/COPYING). Exact revision and archive SHA-256 are recorded in dependencies/snes-core-source.json.
