# Установка, обновление и откат

[English](installation.md)

Rondo устанавливается на Anbernic RG34XXSP с работающей BaseOS. Автоматические
проверки пакета охватывают BaseOS 1.3.0, 1.4.0 и 1.5.3. На приставке сценарии с
двумя картами и Bluetooth проверялись на 1.5.3. См. [совместимость](compatibility.md).

## Первая установка или обновление

1. Скачайте ZIP со [страницы релиза](https://github.com/phoenixweiss/rondo/releases/latest).
   Для новой карты сначала запишите образ BaseOS для **RG34XXSP**, загрузите
   приставку с картой в TF1 и дождитесь, пока BaseOS подготовит раздел данных.
2. Выключите приставку через меню и подключите карту к Mac. Нужны два раздела
   одной карты: раздел данных (обычно `BASEOS`) и загрузочный (обычно `Volumn`).
   Проверьте их через `diskutil list`. Если имена другие, подставьте фактические пути.
3. Возьмите `tools/install_h700.py` из исходников той же версии: они лежат в
   `Sources/rondo-source.tar.gz` внутри ZIP. Нужен Python 3.11 или новее.
   Сначала запустите проверку без записи:

   ```sh
   python3 tools/install_h700.py --package /path/to/Rondo.zip \
     --card /Volumes/BASEOS --boot /Volumes/Volumn
   ```

4. Сверьте показанный UUID раздела данных. Укажите его и новый каталог для
   резервной копии на Mac, вне карты:

   ```sh
   python3 tools/install_h700.py --package /path/to/Rondo.zip \
     --card /Volumes/BASEOS --boot /Volumes/Volumn \
     --backup /path/on/mac/rondo-backup --expected-uuid DATA-UUID --apply
   ```

   При обновлении используются те же команды. Установщик сначала проверяет
   резервную копию, затем заменяет файлы оболочки и при необходимости заставку.
   Игры, сохранения и настройки остаются на карте. Первый оригинал заставки
   сохраняется, а настройка отключения замены заставки учитывается.
5. Безопасно извлеките карту целиком и верните её в TF1. При первой проверке
   оставьте TF2 пустым. Игры размещаются в `RondoGames` на карте данных.
   Для второй карты см. [настройку TF2](storage-layout.md#format-tf2).

## Резервная копия прогресса и откат

Резервную копию прогресса можно создать в меню **Настройки → Резервные копии**.
Скопируйте весь каталог копии на компьютер. Если место хранения резервных копий
не менялось, он находится в `RondoState/Backups` на TF1. См. [состав копии и
восстановление](backups.md).

Если установка прервалась, сначала проверьте состояние карты и отчёт в каталоге
резервной копии. Для отката оболочки восстановите из него прежние файлы оболочки
и сверьте контрольные суммы. Текущие сохранения и `RondoState` восстанавливайте
отдельно, только если вам действительно нужна более ранняя копия прогресса.

Чтобы вернуть оригинальную заставку, используйте настройку в Rondo либо
команду с тем же подтверждённым UUID:

```sh
python3 tools/install_h700.py --card /Volumes/BASEOS --boot /Volumes/Volumn \
  --expected-uuid DATA-UUID --restore-logo --apply
```

Подробности о разделе загрузки и действиях при сбое есть в
[английской инструкции](installation.md).
