# Roadmap

Rondo is early-stage, maintainer-led software. This document describes directions, not delivery dates or a promise that every planned emulator or device will be supported.

## Near term

- Prepare the first versioned release from the public source tree and reproducible runtime.
- Improve everyday RG34XXSP use based on actual device testing.
- Refine library headings, feedback and information screens without losing the working save-slot experience.
- Keep configuration, state storage, installation and rollback documentation aligned with tested behavior.
- Expand hardware regression checks and error diagnostics.

## Later

- A separate Vue website build under website/, with English and Russian content.
- A considered explanation of the Rondo name.
- Investigate more game systems and emulators individually, including runtime, controls, performance and licensing.
- Investigate two-card library behavior and wider H700 hardware support.
- Revisit the contribution process when the architecture and maintenance capacity are more mature.

The public dev branch receives small, verified changes. README capabilities describe the checked-out code. Releases and website deployments have separate verification and versioning.
