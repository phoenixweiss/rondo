# Contributing to Rondo

Rondo is a personal project in early development. The maintainer is currently working through a substantial backlog and shaping the core experience on their own handheld.

Bug reports are welcome. Include the device model, BaseOS and Rondo version or commit, steps to reproduce, expected and actual behavior, and relevant redacted logs. State whether the issue occurs in the desktop prototype or on physical hardware. Please do not upload ROMs, BIOS files, private saves or secrets.

Please open a discussion or issue before starting a substantial pull request. The project is not currently organizing broad community development, and review time or acceptance cannot be promised. Small, agreed fixes are easier to review. This policy can become more open as the architecture and maintenance capacity mature.

Keep changes focused, use short English commit messages and target dev. Update English documentation and the corresponding Russian text together. Run checks relevant to the behavior changed; preserve existing games, settings and save compatibility. Distinguish synthetic tests from physical-device confirmation.

Maintainer releases use Bumpster and the dev → main → dev flow. Ordinary contributions do not bump versions, create tags, publish packages or deploy the website. Those are separate maintainer operations.
