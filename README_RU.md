# Rondo

[English](README.md)

Личный проект владельца Anbernic RG34XXSP. Приставка очень понравилась, подходящего для себя фронтенда не нашлось — поэтому появился Rondo.

**Ранняя разработка.** Существующий рабочий прототип публикуется последовательными наборами исходников. Этот README описывает только текущий набор. Это не стабильная прошивка.

Модель каталога, безопасное хранение и восстановление настроек, English/Russian и полные платформенные политики с синтетическими тестами. Окна приложения и запуска NES здесь ещё нет.

Нужны C++17, make и Python 3.11+. Для SDL-компонентов и приложения также нужны pkg-config, SDL2 и SDL2_ttf.

```sh
make -j4
make test
python3 tools/check_source.py
```

Проверки не устанавливают ничего на SD и не подтверждают работу физических кнопок, яркости или сна. English — основной язык, русский — дополнительный. Наш код — [MIT](LICENSE); чужие компоненты сохраняют [свои условия](THIRD_PARTY_NOTICES.md). ROM/BIOS и пользовательские сохранения не входят в исходники. Существенные PR лучше предварительно обсуждать; сейчас приоритет — бэклог автора.
